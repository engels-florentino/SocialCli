# SocialCli brand assets

The approved SocialCli mark combines **S** for social with **>_** for a command-line terminal. Use this same mark for the repository, documentation, website and provider application identity.

- `socialcli-logo.png`: original square PNG, 1254 × 1254, RGBA, with transparency outside the rounded tile.
- `socialcli-logo-prompt.txt`: generation tool and prompt used to create the original.

Preserve the white S, blue terminal prompt, dark navy tile and aspect ratio. Keep the mark readable at small sizes and leave space around it. Use **SocialCli** as the product name. The site header, favicon, touch icon and sharing metadata use this asset.

The logo identifies the tool. Creator brands and their account avatars remain their own identities.
