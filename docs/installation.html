Install and create your workspace

Requires Python 3.11 or later. Video validation also requires ffprobe, included with FFmpeg, installed on your system.

python -m pip install "git+https://github.com/engels-florentino/SocialCli.git"
socialcli --help
mkdir my-social
cd my-social
socialcli brand new MyBrand

Complete MyBrand/brand.md and MyBrand/accounts.yml. Brand folders contain your operational data: keep them outside the application repository.

Choose another folder

The current folder is the default. Set SOCIALCLI_ROOT to an absolute path or pass --root PATH with each command.

Develop and test

git clone https://github.com/engels-florentino/SocialCli.git
cd SocialCli
uv sync --group dev
uv run pytest
uv run socialcli --help

The command is socialcli. The internal Python package and earlier socialctl alias remain for compatibility. No PyPI release is announced: install from this repository.
