Instala y crea tu espacio de trabajo

Requiere Python 3.11 o superior. Para validar vídeos necesitas ffprobe, incluido en FFmpeg, instalado en tu sistema.

python -m pip install "git+https://github.com/engels-florentino/SocialCli.git"
socialcli --help
mkdir mis-redes
cd mis-redes
socialcli brand new MiMarca

Completa los archivos MiMarca/brand.md y MiMarca/accounts.yml. Las carpetas de tus marcas son datos personales de operación: guárdalas fuera del repositorio del programa.

Elegir otra carpeta

Por defecto se usa la carpeta actual. Puedes usar la variable SOCIALCLI_ROOT con una ruta absoluta o pasar --root RUTA en cada comando.

Desarrollar y probar

git clone https://github.com/engels-florentino/SocialCli.git
cd SocialCli
uv sync --group dev
uv run pytest
uv run socialcli --help

El comando es socialcli. El paquete Python interno y el alias anterior socialctl se conservan para compatibilidad. No hay una publicación en PyPI anunciada: instala desde este repositorio.
