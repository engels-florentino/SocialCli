Política de privacidad

Vigente desde el 6 de octubre de 2026. Responsable del proyecto y de esta web: Engels Florentino.

El programa local

SocialCli procesa las cuentas, textos, archivos de media, tokens y registros que el operador configura para publicar o gestionar su propio contenido. En la distribución actual estos datos se guardan en el ordenador o servidor elegido por el operador, separados por marca. El mantenedor no recibe automáticamente estos archivos ni ofrece un servicio central de cuentas OAuth.

Comunicación con proveedores

Cuando autorizas una cuenta o ejecutas una función, SocialCli envía las solicitudes y los datos necesarios a Google/YouTube, Meta/Facebook/Instagram o TikTok. Si configuras un alojamiento o ejecutor remoto, tus archivos se transfieren al destino que tú estableces. Cada proveedor aplica sus propias políticas y plazos de conservación.

Esta web y GitHub

Esta web está alojada en GitHub Pages. No incluye formularios, publicidad, analítica propia ni scripts de seguimiento. GitHub puede procesar datos técnicos de acceso conforme a su política. Los issues y contribuciones en GitHub son públicos; no envíes secretos ni información personal innecesaria.

Eliminar y revocar

Puedes borrar tus datos locales y revocar permisos desde cada plataforma. Borrar un token local no revoca la autorización remota, y borrar un archivo de media no elimina un post publicado. El contenido enviado a las plataformas se gestiona desde ellas o mediante funciones autorizadas de gestión.

Contacto y cambios

Para consultas de privacidad, escribe a blades3@gmail.com. No incluyas tokens ni claves. Para otras consultas puedes usar el perfil o el repositorio del responsable, sin incluir información sensible en mensajes públicos. Cualquier futuro servicio central de autorización requerirá actualizar esta política antes de operar.
