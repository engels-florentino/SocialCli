Privacy policy

Effective October 6, 2026. Project and website operator: Engels Florentino.

The local application

SocialCli processes accounts, text, media files, tokens and records configured by the operator to publish or manage their own content. In the current distribution, these data are stored on the computer or server chosen by the operator, separated by brand. The maintainer does not automatically receive these files or provide a central OAuth account service.

Communication with providers

When you authorize an account or run a feature, SocialCli sends the necessary requests and data to Google/YouTube, Meta/Facebook/Instagram or TikTok. If you configure remote hosting or a runner, files transfer to your chosen destination. Each provider applies its own policies and retention periods.

This website and GitHub

This website is hosted on GitHub Pages. It includes no forms, advertising, first-party analytics or tracking scripts. GitHub may process technical access data under its policy. GitHub issues and contributions are public; do not send secrets or unnecessary personal information.

Deletion and revocation

You can delete local data and revoke permissions on each platform. Deleting a local token does not revoke remote authorization, and deleting a media file does not remove a published post. Manage submitted content on the platform or through authorized management features.

Contact and changes

For privacy inquiries, email blades3@gmail.com. Do not include tokens or keys. For other questions, use the maintainer's profile or repository without including sensitive information in public messages. Any future central authorization service will require updating this policy before operation.
