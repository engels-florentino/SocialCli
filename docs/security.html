Conserva tus credenciales fuera del código

SocialCli guarda secretos localmente por marca en .secrets/, con permisos restringidos. Son archivos de texto: protege tu usuario del sistema, el disco y tus copias de seguridad.

El repositorio excluye .env, .secrets/, estado local y archivos de creadores. Gitignore no elimina secretos de un historial ya existente. Nunca publiques tokens, client secrets, credenciales SSH ni diagnósticos privados.

Reportar una vulnerabilidad

Usa Security → Report a vulnerability en GitHub. No abras un issue público con credenciales o detalles que permitan acceder a cuentas. Si sospechas exposición, revoca y rota la clave en su proveedor.
