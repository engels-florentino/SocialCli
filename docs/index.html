SocialCli permite a creadores y equipos preparar, revisar y gestionar contenido propio en YouTube, Facebook, Instagram y TikTok desde la terminal.

Instalar SocialCliVer cómo funciona →
socialcli brand new MiMarca
socialcli publish mi-video --brand MiMarca --only tiktok --dry-run

Revisa antes de enviar

Comprueba el texto, la cuenta y los archivos. Confirma cada envío después de ver el preview.

Separa tus marcas

Cada marca conserva sus cuentas, credenciales, publicaciones y registros en su propia carpeta.

Conserva el control

Usa archivos que ya has producido. SocialCli no genera ni recorta media y distingue un envío pendiente de un post publicado.

Una herramienta disponible para otros creadores

Descarga el código, instala el CLI y conecta tus propias cuentas con aplicaciones de proveedor configuradas por ti. No necesitas una cuenta de Histopast ni sus credenciales. Esta distribución no ofrece todavía una autorización OAuth común de SocialCli.

Entiende el flujo de TikTok

El modo inicial es inbox: SocialCli envía tu vídeo al buzón y tú completas la publicación en TikTok. Las APIs de producción y Direct Post requieren las autorizaciones y revisiones del proveedor.

El repositorio público no acredita aprobación de TikTok. Consulta el estado de cada integración y sus requisitos antes de usarla.

Documentación y soporte

Consulta la instalación, la guía de publicación, las plataformas y la seguridad. El proyecto lo mantiene Engels Florentino; puedes informar de errores en GitHub sin exponer credenciales.
