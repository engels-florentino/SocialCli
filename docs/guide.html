From your file to the preview

  1. Create a brand and configure its accounts.
  2. Authorize your accounts with socialcli auth PLATFORM --brand MyBrand.
  3. Save the produced file under MyBrand/media/my-video.mp4.
  4. Create MyBrand/posts/my-video/post.yml with your post content.
  5. Display the complete preview with --dry-run and approve the submission if correct.
  6. Verify the platform result before retrying.

TikTok inbox example

slug: my-video
campaign: vertical-clip
platforms:
  tiktok:
    body: "A story worth telling."
    hashtags: []
    media: ["my-video.mp4"]
socialcli publish my-video --brand MyBrand --only tiktok --dry-run
socialcli publish my-video --brand MyBrand --only tiktok

The first command does not publish. The second requests confirmation. In inbox mode, a pending confirmation status means you must complete the post in TikTok; it does not confirm public publication.

Diagnostics and content

socialcli auth status --brand MyBrand --platform tiktok --json
socialcli doctor --brand MyBrand --json
socialcli capabilities --brand MyBrand --json
socialcli content --help
socialcli stats --help
socialcli native-schedule --help

Management, catalog and metrics permissions may differ from publishing permissions. Use --help with each command to see its options. A valid connection does not establish every permission or feature availability for every account.
