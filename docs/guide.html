De tu archivo al preview

  1. Crea una marca y configura sus cuentas.
  2. Autoriza tus cuentas con socialcli auth RED --brand MiMarca.
  3. Guarda el archivo ya producido bajo MiMarca/media/mi-video.mp4.
  4. Crea MiMarca/posts/mi-video/post.yml con el contenido de la publicación.
  5. Muestra el preview con --dry-run y confirma el envío si es correcto.
  6. Verifica el resultado en la plataforma antes de reintentar.

Ejemplo para el buzón de TikTok

slug: mi-video
campaign: clip-vertical
platforms:
  tiktok:
    body: "Una historia que vale la pena contar."
    hashtags: []
    media: ["mi-video.mp4"]
socialcli publish mi-video --brand MiMarca --only tiktok --dry-run
socialcli publish mi-video --brand MiMarca --only tiktok

El primer comando no publica. El segundo solicita confirmación. En inbox, pending_confirmation significa que debes completar el post en TikTok; no confirma una publicación pública.

Diagnóstico y contenido

socialcli auth status --brand MiMarca --platform tiktok --json
socialcli doctor --brand MiMarca --json
socialcli capabilities --brand MiMarca --json
socialcli content --help
socialcli stats --help
socialcli native-schedule --help

Los permisos de gestión, catálogo y métricas pueden ser distintos de los de publicación. Usa --help en cada comando para consultar sus opciones. Una conexión válida no acredita todos los permisos ni disponibilidad para todas las cuentas.
