Conecta tus propias cuentas

Esta versión usa aplicaciones de desarrollador configuradas por cada operador. SocialCli no distribuye secretos compartidos ni facilita las credenciales de Histopast. Las plataformas determinan permisos, cuotas y acceso de producción.

YouTube

Crea un proyecto en Google Cloud, habilita YouTube Data API y las APIs de métricas que vayas a usar, configura el consentimiento y un cliente OAuth de escritorio. Ejecuta socialcli auth youtube --brand MiMarca. Para métricas o gestión pueden ser necesarios permisos adicionales.

Facebook e Instagram

Configura una aplicación de Meta y sus permisos. El flujo de Facebook publica en Páginas; Instagram usa una cuenta profesional vinculada a una Página. Ejecuta socialcli auth facebook o socialcli auth instagram con --brand MiMarca. Instagram requiere URLs HTTPS accesibles para descargar tus archivos.

TikTok

Configura Login Kit y Content Posting API en tu aplicación de escritorio. El callback local es http://localhost:8723/callback. Para inbox, solicita user.info.basic y video.upload; añade tu cuenta como target si estás en sandbox. Ejecuta socialcli auth tiktok --brand MiMarca.

La plantilla mantiene mode: inbox y auditada: false. Una subida al buzón no demuestra aprobación de producción.

Direct Post: requisitos pendientes

El adaptador consulta creator info, comprueba duración y exige la marca de auditoría, pero faltan controles completos para elegir privacidad sin valor por defecto, interacciones y divulgación comercial. No actives este modo como si el producto ya estuviera aprobado. La distribución pública tampoco resuelve por sí sola una autorización común para todos los usuarios.
