Connect your own accounts

Connect through the shared SocialCli service when a platform is configured and your account is eligible. Creators authorize their own account in the browser without developer registration or shared application secrets. Independent operator-managed apps remain available. Platforms determine permissions, quotas and production access.

YouTube

Run socialcli connect youtube --brand MyBrand. Add --analytics for watch time, average view duration and other authorized YouTube Analytics reports; add --management for metadata operations. The hosted Google app is currently in Testing and restricted to authorized test users. Independent mode uses socialcli auth youtube with an operator-configured desktop client.

Facebook and Instagram

For eligible accounts, use socialcli connect facebook or socialcli connect instagram with --brand MyBrand. Add --management for comment management and --analytics for insights. Facebook publishes to Pages; Instagram requires a linked professional account and accessible HTTPS media URLs. Independent operator applications remain supported through socialcli auth. App review, Page tasks and actual consent still determine access.

TikTok

For eligible target accounts, use socialcli connect tiktok --brand MyBrand with the configured shared service. TikTok sandbox access is restricted to authorized targets. Independent operator mode uses Login Kit and Content Posting API with socialcli auth tiktok; its local callback is http://localhost:8723/callback. Inbox requires user.info.basic and video.upload.

The template retains mode: inbox and auditada: false. An inbox upload does not establish production approval.

Direct Post: outstanding requirements

The adapter queries creator info, checks duration and requires the audit flag, but complete controls for selecting privacy without a default, interactions and commercial disclosure are missing. Do not activate this mode as though the product were approved. Public distribution alone does not provide shared authorization for all users.

Community verification

Facebook likes require a connected Page token, pages_manage_engagement, the applicable Page task and an eligible object. App settings do not prove granted creator permissions. SocialCli currently proposes likes on owned Page content. YouTube video ratings are supported; YouTube comment likes/hearts and Instagram/TikTok comment likes are not supported. Direct Meta comment verification requires exact actor, parent/media and text evidence. Ambiguous writes remain uncertain and are never automatically repeated. Synthetic tests do not establish production eligibility.
