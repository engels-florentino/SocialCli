Connect your own accounts

This release uses developer applications configured by each operator. SocialCli does not distribute shared secrets or another creator's credentials. Platforms determine permissions, quotas and production access.

YouTube

Create a Google Cloud project, enable YouTube Data API and any required metrics APIs, configure consent and a desktop OAuth client. Run socialcli auth youtube --brand MyBrand. Metrics and management may require additional permissions.

Facebook and Instagram

Configure a Meta application and its permissions. Facebook publishes to Pages; Instagram uses a professional account linked to a Page. Run socialcli auth facebook or socialcli auth instagram with --brand MyBrand. Instagram requires accessible HTTPS URLs to download your files.

TikTok

Configure Login Kit and Content Posting API in your desktop application. The local callback is http://localhost:8723/callback. For inbox, request user.info.basic and video.upload; add your account as a target user in sandbox. Run socialcli auth tiktok --brand MyBrand.

The template retains mode: inbox and auditada: false. An inbox upload does not establish production approval.

Direct Post: outstanding requirements

The adapter queries creator info, checks duration and requires the audit flag, but complete controls for selecting privacy without a default, interactions and commercial disclosure are missing. Do not activate this mode as though the product were approved. Public distribution alone does not provide shared authorization for all users.
