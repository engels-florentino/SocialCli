# rc7 verification — 15 October 2026

This candidate includes every fix in [the rc6 audit](audit-rc6-2026-10-15.md).
The rc6 release workflow was cancelled before publication to include the owner's
additional UI requests. Its tag remains immutable; rc5 is still the public pilot.

Each recognized network supplies its local favicon, correct MIME type, browser
title, header label and mobile app icon. Account selection and confirmation retain
that network identity. The login button continues to name the actual provider
(Google for YouTube; Facebook for Instagram). Generic errors with no validated
network context retain SocialCli identity. Authentication and approval are unchanged.

After selection, the browser tells the user they may close the page and continue
with their assistant, with a My Account link. It also asks them to keep SocialCli
running until local activation finishes; selection is not misreported as completed
activation or publication. All visible copy remains English.

The three operator-supplied icons are preserved byte-for-byte and displayed with
CSS at 64px desktop/58px mobile. No cropping, reencoding or external image fetch.

Independent review found an undefined platform interpolation in generic error
rendering; removed it before release. Existing expired-link/invalid-callback tests
and targeted SaaS connection/auth UI tests pass (59 tests). The final full suite,
archive allowlist, clean installation and protected publication are verified in
sequence before public rollout. No live social write is part of this verification.
